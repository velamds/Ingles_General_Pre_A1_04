## Uso sin LMS (GitHub Pages)

`static/application/js/scorm_local_api.js` simula la API SCORM 2004 de un LMS y guarda el
progreso en el `localStorage` del navegador. Dentro de un LMS real no se activa.

- Al volver a abrir un objeto, pregunta si se desea continuar donde se quedó.
- Para borrar el progreso guardado: abrir el objeto con `?reset=1` al final de la URL.
- El progreso se guarda por navegador y dispositivo (no se comparte entre equipos).
